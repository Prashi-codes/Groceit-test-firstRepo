Groceit is a modern grocery shopping Android application designed to make grocery management simple and efficient. Users can browse products, add items to the cart, manage orders, and enjoy a smooth shopping experience.

✨ Features
🔍 Search and browse grocery products
🛍️ Add and remove items from cart
❤️ Wishlist support
📦 Order management
🔔 Push notifications using Firebase Cloud Messaging (FCM)
🔐 User authentication (Login/Signup)
🌙 Clean and user-friendly UI
⚡ Fast and responsive performance
🛠️ Built With
Kotlin
Android Studio
Jetpack Compose / XML (choose whichever you used)
Firebase Authentication
Firebase Firestore
Firebase Cloud Messaging (FCM)
MVVM Architecture

🚀 Getting Started
Prerequisites
Android Studio Hedgehog or later
JDK 17+
Firebase Project
Installation
Clone the repository:
git clone https://github.com/yourusername/Groceit.git
Open the project in Android Studio.
Add your google-services.json file inside the app/ directory.
Sync the project with Gradle.
Run the application on an emulator or physical device.
